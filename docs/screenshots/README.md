# Screenshots

Public build (`play`), English UI, country set to United States, captured on the Android TV
emulator (Google TV, API 34). Live TV uses the public [iptv-org](https://github.com/iptv-org/iptv)
US playlist as a demo source. Film and TV artwork comes from TMDB and is shown for illustration
only; it belongs to its respective owners.

## 1280×720

The same layout scaled down for 720p TVs: [home](1280x720/01-home.png),
[Cinema](1280x720/02-cinema-hero.png), [rows](1280x720/03-cinema-rows.png),
[Likhtaryk](1280x720/06-likhtaryk.png), [title page](1280x720/08-title.png).

4K (3840×2160) is not included: the emulator does not allow a display larger than its
physical 1080p size. The UI is laid out in dp on a 960×540 canvas, so 4K renders the same layout.
