# Games in Likhtar Home

**English** · [Українська](games.uk.md)

The Games section is off by default. Turn it on in *Settings → Home → Games*.

## Cloud gaming

Boosteroid, Xbox Cloud Gaming, GeForce NOW and PS Remote Play sit in the first row. If an app is
installed, OK opens it; if not, OK takes you to its store page.

## Your own ROMs

1. Install RetroArch.
2. In RetroArch, download the core for your console once (*Online Updater → Core Downloader*):
   Gambatte for Game Boy, FCEUmm for NES, Snes9x for SNES, Genesis Plus GX for Mega Drive.
3. Put ROM files into a `ROMs` folder on the TV or a USB stick, or send them from your phone
   (*Settings → From your phone*).

They show up as boxes with art from the libretro database, with a real frame from the game behind
the title. OK starts the game in RetroArch with the right core, no menus. *Continue playing* keeps
what you played last on top.

To see ROMs copied from a USB stick, allow Likhtar access to all files (*Settings → Home → Games
from USB*; on Google TV it opens the system list, find Likhtar Home there).

## Installed games

Installed games and emulators sit below. Any app can be moved here with a long press →
*Category*.

Likhtar does not include or download any games. Box art and screenshots come from
[libretro-thumbnails](https://github.com/libretro-thumbnails); service names and icons belong to
their owners.
