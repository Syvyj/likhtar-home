# Ігри в Likhtar Home

[English](games.md) · **Українська**

Розділ «Ігри» за замовчуванням вимкнено. Увімкніть його в *Налаштування → Головна → Ігри*.

## Хмарні ігри

Boosteroid, Xbox Cloud Gaming, GeForce NOW і PS Remote Play стоять у першому ряду. Якщо застосунок
встановлений, OK відкриває його; якщо ні — веде на його сторінку в магазині.

## Ваші образи ігор

1. Встановіть RetroArch.
2. У RetroArch один раз завантажте ядро для своєї консолі (*Online Updater → Core Downloader*):
   Gambatte для Game Boy, FCEUmm для NES, Snes9x для SNES, Genesis Plus GX для Mega Drive.
3. Покладіть образи в теку `ROMs` на телевізорі чи флешці або передайте з телефона
   (*Налаштування → З телефона*).

Вони з'являться коробками з обкладинками з бази libretro, а за назвою — справжній кадр із гри. OK
запускає гру в RetroArch одразу з потрібним ядром, без меню. «Продовжити гру» тримає останні згори.

Щоб лаунчер бачив образи, скопійовані з флешки, дайте йому доступ до всіх файлів (*Налаштування →
Головна → Ігри з флешки*; на Google TV відкриється системний список, знайдіть там Likhtar Home).

## Встановлені ігри

Нижче — встановлені ігри й емулятори. Будь-який застосунок можна перенести сюди довгим OK →
*Категорія*.

Самих ігор Likhtar не містить і не завантажує. Обкладинки й кадри — з
[libretro-thumbnails](https://github.com/libretro-thumbnails); назви й значки сервісів належать їхнім
власникам.
